# CE-LAB

Compiler Engineering Laboratory programs and experiments implemented as part of academic coursework.

## 📘 About

This repository contains lab experiments related to **Compiler Engineering**, including optimization techniques, intermediate code generation, control flow conversion, scheduling algorithms, and backend code generation.

## 📂 Experiments Included

### 🔹 EXP8_IF_ELSE_TO_SWITCH
Program to convert `if-else-if` ladder statements into equivalent `switch-case` statements where possible.

### 🔹 EXP9_INTERMEDIATE_CODE
Implementation of intermediate code generation for expressions/statements.

### 🔹 EXP10_COMMON_SUBEXPRESSION
Program to detect and eliminate common subexpressions for code optimization.

### 🔹 EXP11_BACKEND_CODE_GENERATOR
Simple backend code generator to convert intermediate representation into target machine-like code.

### 🔹 EXP12_LOCAL_LIST_SCHEDULING
Implementation of local list scheduling algorithm for instruction scheduling optimization.
